# Elefante Scripts Directory

Every Python file in this directory has a uniquely important, explicit purpose, classified into dedicated subdirectories. This avoids redundancy and ensures clarity for continuous integration, deployment, and debugging.

For repository debugging, choose scripts through [`docs/debug/dev-developer-agent.md`](../docs/debug/dev-developer-agent.md). `scripts/verify/` is for purposeful validation. `scripts/debug/` is for non-routine intervention only when a compendium explicitly directs it.

## `scripts/setup/` — Active Production & Delivery

| Script | Purpose & Uniqueness | Importance |
|---|---|---|
| `install.py` | Single-entry universal installer for the Elefante server, managing venv, dependencies, and pathing. | **Critical** (Client setup entrypoint) |
| `configure_vscode_bob.py` | Generates the specifically required JSON schema to inject Elefante MCP configuration into Bob IDE (VS Code fork). | **Critical** (IDE integration) |
| `configure_antigravity.py` | Equivalent to Bob script, but outputs the specific format required by the Antigravity IDE plugin structure. | **Critical** (IDE integration) |
| `init_databases.py` | Safe bootstrap script strictly for initializing/re-verifying ChromaDB collections and Kuzu table schemas locally. | **Critical** (Database safety) |

## `scripts/verify/` — Health & Validation

| Script | Purpose & Uniqueness | Importance |
|---|---|---|
| `verify_health.py` | Performs a system-wide structural check (paths, python versions, import readiness) strictly for the core engine. | **High** (Deployment & pre-commit) |
| `verify_dashboard_health.py` | Executes independent HTTP protocol checks on the Dashboard React server, isolated from core engine testing. | **High** (Dashboard stability) |
| `verify_mcp_handshake.py` | Standalone protocol verification script simulating an MCP heartbeat to ensure the server communicates correctly. | **High** (Protocol verification) |
| `verify_e2e_tests.py` | Launches the real MCP server in an isolated temporary Elefante home/data dir and proves handshake, directive injection, specification baseline seeding, restart persistence, compliance gate behavior, and the shutdown-race regression path. | **High** (Release confidence) |
| `verify_dashboard_snapshot.py` | Verifies the snapshot `.json` structural integrity generated by the pipeline to prevent React rendering crashes. | **High** (Dashboard stability) |
| `verify_emoji_policy.py` | Regex-driven linter enforcing the absolute "no emojis in strict docs" policy during commit sequences. | **Medium** (Codebase etiquette) |

## `scripts/debug/` — Raw Interventions

Only invoke these explicitly during severe operational failure modes (locks, database freezing, corruption).

| Script | Purpose & Uniqueness | Importance |
|---|---|---|
| `dump_memories_all.py` | Raw ChromaDB stdout dump bypassing orchestration filters to let developers forcibly view hidden strings. | **High** (Developer visibility) |
| `list_memories_recent.py` | Lightweight orchestrator query strictly returning the 10 most recent events for rapid testing validation. | **Medium** (Agile testing) |
| `unlock_database_transactions.py` | Destructive intervention explicitly killing frozen SQLite or Chroma transaction locks blocking memory writes. | **High** (Database recovery) |
| `remove_lock_kuzu.py` | Equivalent unlock tool targeting specifically the Kuzu knowledge graph lockfiles (separate subsystem). | **High** (Database recovery) |
| `reset_kuzu_nuclear.py` | Total isolation wipe purely for the Kuzu graph database when it becomes corrupt independent of the Chroma vectors. | **High** (Database recovery) |

## `scripts/privileged/` — Deep Overrides

| Script | Purpose & Uniqueness | Importance |
|---|---|---|
| `delete_memories_surgical.py` | Precise surgical excision of specific memory IDs spanning both vector and graph databases synchronously. | **Critical** (Targeted maintenance) |
| `inspect_memory_graph.py` | Agnostic read-only connectivity scanner for finding the semantic neighbors surrounding a target UUID. | **Critical** (Graph visualization) |
