# Elefante: The Core

Elefante exists to bridge the cognitive gap between human intent and agentic execution through **Persistent Cognitive Continuity**.

It is the machine-resident nervous system that allows AI agents to stop restarting and start evolving.

---

## The Three Laws

1. **Continuity** — A session is never new; it is a continuation. Act on the established identity, preferences, and progress of the user.

2. **Compliance** — Search before you act. `elefante-MemorySearch` before any answer or write. Ignorance is a choice, not a constraint.

3. **Grounding** — If it is not in the Brain or the Workspace, it is UNKNOWN. Do not hallucinate, approximate, or assume.

---

## The Cardinal Sins

- **Statelessness**: asking for information already stored in the Brain
- **Hallucination**: guessing a path, API, or user preference
- **STDOUT Pollution**: printing logs to the MCP stream (kills the connection)
- **Redundancy**: creating a new file where an augmentation path exists
